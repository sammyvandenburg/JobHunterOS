## One workflow contract
The skill (`board.md`, `cloud.md`, `hunting.md`, `troubleshooting.md`), `jobhunter plan` and the cloud
routine prompt now agree: read dashboard → run requests → hunt → digest (prepare, send, record) → save →
export, batch write, `board published`. A run that skipped the confirmation reports "written, not published".
